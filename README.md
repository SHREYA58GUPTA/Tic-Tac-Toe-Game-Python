❌⭕ Tic Tac Toe Game

A simple and interactive **Tic Tac Toe (X-O) game** developed using Python. This project demonstrates basic game logic, user interaction, and GUI implementation.

---
Project Overview
This is a classic two-player Tic Tac Toe game where players take turns marking spaces in a 3×3 grid. The player who succeeds in placing three of their marks in a row, column, or diagonal wins the game.

---

 🎮 Features
- Two-player gameplay  
- Interactive game interface  
- Win and draw detection  
- Simple and clean design  
- Easy to understand logic
